Research Digest

An offline-first companion for keeping up with research.

This is a progressive web app you can install to your devices. It fetches papers from arXiv, Semantic Scholar, and OpenReview, then summarizes and tags them with tiny offline DistilBERT models running entirely on your own device — no API keys, no cloud, no account. Free forever.

Open the app Contribute / file issues
  • Fetching, scoring, and summarization all run in your browser.
  • Your interests and saved papers stay on this device — no account, nothing synced.
  • Works offline after your first visit; a small relay only proxies the few source APIs that don't allow direct browser requests.
